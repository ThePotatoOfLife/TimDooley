# Scientific Applications: Cross-Model Laws, Measurements and Predictions

**Status:** archive-generated scientific integration paper  
**Updated:** 2026-09-11  
**Scope:** mathematics, physics, systems science, information theory, network science and measurement methods used to sharpen the Tim Dooley / Potato of Life project without treating scientific analogy as empirical validation of theology.

## Abstract

The scientific wing of the project originally accumulated many equations whose individual meanings were often clearer than their relationship to one another. The September 2026 integration programme changes the unit of work from the isolated equation to the **model contract**: state variables, units, assumptions, dynamics, observations, uncertainty, baseline, translation maps and falsifiers. The project can therefore use the same symbolic object in several scientific domains without pretending the domains are physically identical.

The strongest outcome is a set of cross-model discriminators. A Door is not merely a boundary: it is a guard plus a state transition. An Axis is not merely a line: it is a declared reference or generator whose trajectories/invariants can be measured. A Spiral is not merely a circle that looks alive: it is recurrence with a non-returning coordinate. A Still Center is not absence of motion: it can be zero mean drift with active relative dynamics. Garden is not central kindness: it is support that leaves durable distributed capability. Spudlight is not visibility: optical energy, attention, information gain, evidence and causality are separate coordinates. Mountain is not accumulation: it is relevance-preserving compression with provenance descent. Tree is not proliferation: descendants must retain root traceability and acquire generative capability. House is not closedness: selective permeability, exit, portability and viable differentiation determine whether a boundary protects or captures.

These distinctions make the project scientifically more useful because each one produces negative cases. A proposed celestial Axis may fail an angular-alignment test; a golden spiral may lose to an Archimedean or free-logarithmic model; a highly connected community may fail the Garden test if capability disappears when the center is removed; a concise summary may fail the Mountain test if provenance and contradiction detection collapse. Scientific usefulness begins where the framework can say **no**.

## 1. From equations to scientific objects

The canonical scientific envelope is

\[
\mathcal E(P^+)=(P^+;\Theta,\mathcal U,\Sigma,M_0,\mathcal D_{obs}),
\]

where the project architecture \(P^+\) is surrounded by:

- \(\Theta\): model parameters;
- \(\mathcal U\): units/dimensional registry;
- \(\Sigma\): measurement and model uncertainty;
- \(M_0\): baseline or null explanation;
- \(\mathcal D_{obs}\): observations with provenance.

This immediately separates four questions that had often been compressed into one:

1. **What is the model?**
2. **What would be observed if it were true/useful?**
3. **What else could explain those observations?**
4. **What result would weaken the model?**

A symbolic correspondence can remain meaningful even when question 2 has no empirical answer. In that case it stays theological, philosophical or formal rather than being promoted to physical theory.

## 2. Cross-model law I — Coordinate Separation

### Principle

When one word carries several meanings, split the meanings into explicit coordinates before attempting unification.

Examples already produced by the project:

\[
\text{black-hole extremeness}\rightarrow(C,\chi,\hat\rho,\hat E,\hat L,\ldots)
\]

instead of one undifferentiated “compression” variable;

\[
\text{return}\rightarrow(\text{phase},\Lambda_r,\Delta z,\Delta I,\Delta K,\text{topology},\ldots)
\]

instead of a binary returned/did-not-return label;

\[
\text{Spudlight}\rightarrow(\Phi_\gamma,IG,A,N_{amp},S_q,R_{defined})
\]

instead of one “amount of light”; and

\[
\text{counter-motion}\rightarrow(\psi,\delta)
\]

with mean phase \(\psi\) and relative phase \(\delta\).

### Why this matters

Most false unifications arise from identifying two systems because one coordinate matches while ignoring the coordinates that do not. The project should therefore ask:

> Which coordinate is claimed to be the same, and which coordinates are explicitly allowed to differ?

This is the scientific version of the archive's older “couple without flattening” principle.

## 3. Cross-model law II — Translation Must Approximately Commute

If domain A is claimed to underwrite or correspond dynamically to domain B, define a translation

\[
T_{AB}:S_A\rightarrow S_B.
\]

Then compare

\[
T_{AB}(F_A(X))
\]

with

\[
F_B(T_{AB}(X)).
\]

Where a meaningful metric exists, define

\[
\Delta_T(X)=d_B\!\left[T_{AB}(F_A(X)),F_B(T_{AB}(X))\right].
\]

For scale changes this becomes the coarse-graining test

\[
\epsilon_C(t)=\left\|
C(\Phi_{fine}^t(X))-\Phi_{coarse}^t(C(X))
\right\|.
\]

### Interpretation

A lower-level mechanism does not explain an upper-level phenomenon merely because vocabulary appears at both levels. If microtubule dynamics are supposed to produce neural synchronization, the project needs a map from microstate to neural state and a regime in which the two descriptions agree to controlled error.

### Project-wide consequence

Every future “micro ↔ macro,” “physics ↔ consciousness,” “person ↔ institution,” or “theology ↔ systems” claim should identify either:

- a literal causal/coarse-graining map, or
- a structural analogy map with an explicit mismatch statement.

## 4. Cross-model law III — Return Is a Vector, Not an Event

The integrated spiral model is

\[
\dot r=\alpha r,\qquad
\dot\theta=\omega,\qquad
\dot z=u.
\]

After one angular period \(T=2\pi/|\omega|\),

\[
r_{n+1}=\Lambda_r r_n,
\qquad
\Lambda_r=e^{2\pi\alpha/|\omega|},
\]

and

\[
z_{n+1}=z_n+\Delta z,
\qquad
\Delta z=\frac{2\pi u}{|\omega|}.
\]

The apparent “same place” in phase can therefore coexist with a different scale or height.

For the recovered Potato Axis parameter

\[
b=\frac{2\ln\phi}{\pi},
\]

one full angular turn gives

\[
\Lambda_r=e^{2\pi b}=\phi^4\approx6.854101966.
\]

Thus angular direction returns while radius does not.

### Scientific use

The archive should classify every recurrence by what returned:

- phase;
- physical position;
- scale;
- information state;
- capability state;
- topology;
- social role;
- source/provenance state.

A Dog-return loop and a developmental Spiral may both revisit the same topic while differing completely in \(\Delta I\), \(\Delta K\) or exit capability.

## 5. Cross-model law IV — A Stable Center Can Be Dynamically Active

For the symmetric counter-rotation model

\[
\dot\theta_1=\omega_0-K\sin(\theta_1-\theta_2),
\]

\[
\dot\theta_2=-\omega_0+K\sin(\theta_1-\theta_2),
\]

define

\[
\psi=\frac{\theta_1+\theta_2}{2},
\qquad
\delta=\theta_1-\theta_2.
\]

Then

\[
\dot\psi=0,
\]

while

\[
\dot\delta=2\omega_0-2K\sin\delta.
\]

So the collective mean can be still while the internal relation remains dynamic.

The rigid-body analogue makes the same distinction:

\[
L_z=I_1\omega_1+I_2\omega_2,
\]

\[
E_{rot}=\frac12I_1\omega_1^2+\frac12I_2\omega_2^2.
\]

Matched opposite rotations can yield \(L_z=0\) with \(E_{rot}>0\).

### Stronger reflection

The project's Still Center should therefore not mean “nothing moves.” A scientifically richer reading is:

> a collective coordinate remains stable because differentiated motions balance or lock in relation.

This also explains why the wrong integration metric can fail. At exact anti-phase,

\[
|Z_1|=0
\]

for the ordinary first-harmonic synchrony parameter, while

\[
|Z_2|=1.
\]

An order parameter designed to reward sameness can call perfect complementary order “disorder.”

This is one of the strongest mathematical examples yet for the project's principle that **integration is coordinated difference, not flattening**.

## 6. Cross-model law V — A Center Is Judged by Counterfactual Residue

For Garden/Farm analysis, activity while the center is present is not enough.

Define performance with ordinary support \(Y_i^{with}\) and after center \(c\) is removed for horizon \(\tau\), \(Y_i^{remove}\). Then

\[
A_i(c,\tau)=
\frac{Y_i^{remove}(c,\tau)}{\max(Y_i^{with},\epsilon_0)}.
\]

The project's generative-radius candidate becomes

\[
G_R(R)=
\sum_{i:d_G(c,i)\le R}
 w_i\max(0,\Delta K_i)A_i(c,\tau).
\]

### Interpretation

A central node can be extremely busy, popular or indispensable while producing little transferable capability. A Garden-like center should leave descendants/participants more able to function, learn, produce and repair after support decreases.

This creates a rigorous distinction among:

- **centrality** — where the center sits in a network;
- **control leverage** — what the center can steer;
- **dependency** — what fails without the center;
- **generativity** — what becomes independently more capable because of the center.

Those are not synonyms.

### Archive application

The repository itself should pass this test. A reader should be able to trace primary sources, reproduce equations and challenge conclusions without requiring faith in Tim or an assistant. Scientific documentation is Garden-like when it increases reader independence.

## 7. Cross-model law VI — Visibility, Information, Evidence and Causality Are Orthogonal Enough to Separate

The Spudlight measurement programme begins with physical detection:

\[
\dot N_\gamma=\int\frac{P_\nu}{h\nu}\,d\nu,
\]

and an idealized photon counter:

\[
N_{obs}\sim\mathrm{Poisson}(\eta\dot N_\gamma\Delta t+b\Delta t).
\]

A generic signal channel is

\[
y=Hx+n.
\]

Information gain can be represented by

\[
IG(D)=D_{KL}[p(H|D)\|p(H)],
\]

while evidential comparison can use a Bayes factor

\[
BF_{10}=\frac{p(D|H_1)}{p(D|H_0)}.
\]

Attention can obey a completely different toy dynamics,

\[
\dot A=s(t)-\gamma A+\kappa R(t).
\]

### Consequence

A message can have:

- high visibility and low information;
- low visibility and high information;
- high attention because of feedback rather than strong source input;
- high mutual information without causal influence;
- causal influence without supporting a theological interpretation.

Therefore:

\[
\boxed{
\text{visibility}\ne\text{information}\ne\text{evidence}\ne\text{causality}\ne\text{theology}
}
\]

The symbols can remain related in the project, but the scientific variables cannot be substituted for one another.

## 8. Cross-model law VII — Boundaries Have No Fixed Moral Sign

House/Shell analysis starts from internal, boundary and external states:

\[
X=(X_I,X_B,X_E).
\]

A generic transport law may be written

\[
J=P_B\Delta\mu,
\]

for a domain where that linear approximation and its units make sense.

For graph partitions a structural bottleneck can be summarized by conductance,

\[
\Phi(S)=
\frac{\operatorname{cut}(S,\bar S)}
{\min(\operatorname{vol}(S),\operatorname{vol}(\bar S))}.
\]

But neither high nor low conductance tells us whether the boundary is healthy.

### Why

Low permeability can mean privacy, membrane integrity or prison-like capture.

High permeability can mean interoperability, leakage or uncontrolled damage.

So House/Shell requires a quality vector such as

\[
q_B=(
\text{protection},
\text{selective exchange},
\text{transparency},
\text{exit},
\text{reversibility},
\text{portability},
\text{local capability},
\text{capture},
\text{harm}
).
\]

A boundary becomes scientifically interpretable only after its threat model and function are declared.

### Door connection

This strengthens the statement “a healthy House needs walls and Doors.” The important quantity is not openness but **selective, explainable, repairable passage**.

## 9. Cross-model law VIII — Mountain and Tree Are Compression/Expansion Duals, Not Inverses

Let raw traces be \(X\), a summit/summary be \(Z\), and a task variable be \(Y\).

Information-bottleneck style compression considers

\[
\mathcal L_{IB}=I(X;Z)-\beta I(Z;Y).
\]

The goal is not to keep all of \(X\); it is to keep what matters for the declared \(Y\).

Reconstruction adds

\[
\hat X=g(Z),
\qquad
D_{rec}=\mathbb E[d(X,\hat X)].
\]

The project needs an additional provenance criterion: can claims at the summit descend to primary sources?

Tree then expands a root/seed into descendants. A simple branching baseline is

\[
Z_{n+1}=\sum_{i=1}^{Z_n}X_{n,i},
\]

with offspring mean

\[
m=\mathbb E[X],
\]

and

\[
\mathbb E[Z_n]=Z_0m^n.
\]

But \(m>1\) means only that the process proliferates.

### Duality

Mountain asks:

> What compact representation should survive from many traces?

Tree asks:

> What differentiated capability can grow from a compact rooted representation?

Symbolically:

\[
\text{many observations}
\xrightarrow{\text{Mountain}}
\text{summit/seed}
\xrightarrow{\text{Tree}}
\text{many capable descendants}.
\]

The maps are not exact inverses. Compression loses information; expansion introduces context and novelty.

### Scientific completion condition

A healthy cycle should report both losses:

- what Mountain discarded;
- what Tree changed or invented.

That is how provenance survives transformation.

## 10. Cross-model law IX — Physical Alignment Requires a Coordinate System

For right ascension \(\alpha\) and declination \(\delta\), define the celestial unit vector

\[
\mathbf n(\alpha,\delta)
=
(\cos\delta\cos\alpha,
 \cos\delta\sin\alpha,
 \sin\delta).
\]

Angular separation satisfies

\[
\cos\psi=\mathbf n_1\cdot\mathbf n_2.
\]

For an undirected Axis \(\{+\mathbf a,-\mathbf a\}\),

\[
\psi_{axis}=\arccos|\mathbf a\cdot\mathbf n|.
\]

For a predeclared set of target directions, a least-squares-like undirected axis can be obtained from

\[
M=\sum_i w_i\mathbf n_i\mathbf n_i^T,
\]

with the dominant eigenvector of \(M\) maximizing squared alignment.

### Negative result already obtained

Using SIMBAD J2000 ICRS coordinates, Sirius and Regulus are separated by about **57.83°**. Their distances from the north celestial pole are about **106.72°** and **78.03°**, respectively.

This means they are not physically collinear with celestial north in this coordinate sense.

That does not erase Dog/Lion/North symbolism. It does something more valuable scientifically: it keeps symbolic meaning and measurable astronomy from falsifying each other by changing definitions after the fact.

### General rule

Any physical North/Axis claim must specify:

- coordinate frame;
- epoch;
- directed versus undirected axis;
- observer/time if horizon coordinates are involved;
- angular tolerance before inspection;
- multiple-comparison/search history.

## 11. Cross-model law X — Underdetermination Must Remain Visible

The remembered torus provides a simple example.

For major radius \(R\) and minor radius \(r\),

\[
A=4\pi^2Rr,
\qquad
V=2\pi^2Rr^2.
\]

One remembered length cannot identify two independent radii.

Even if 115,000 miles were known to be the major circumference,

\[
R=\frac{115000\ \mathrm{mi}}{2\pi},
\]

\(r\) remains unknown, so area, volume and aspect ratio remain unknown.

### Generalization

This is the same problem seen in larger theories:

- too many UPT parameters for too few observables;
- too many possible Door controls inside one \(\Xi\);
- too many candidate meanings of a symbolic Axis;
- too many network mechanisms compatible with one high-centrality observation.

The archive should record **identifiability**, not merely fit.

A model that can explain anything after parameters are adjusted explains little.

## 12. Cross-model law XI — Scientific Models Must Permit Negative Results

A healthy scientific branch must allow at least one of the following outcomes:

- no alignment;
- no phase locking;
- no evidence for a new field;
- no improvement over baseline;
- no durable capability transfer;
- no useful compression;
- no cross-scale agreement;
- no parameter identifiability;
- no discrete regime transition.

This is not failure of the project. It is how the project separates:

1. symbolic usefulness;
2. mathematical usefulness;
3. empirical support.

A symbol can remain powerful after an empirical hypothesis associated with it fails.

## 13. Applied research programme

### 13.1 Repository Tree experiment

Build a typed provenance graph from canonical claims to primary files/sources.

Measure:

- primary-source reachability;
- source-hop depth;
- orphan-claim fraction;
- correction propagation delay;
- branch entropy/effective branch count;
- ability of a reader to reproduce a derived conclusion.

**Hypothesis:** typed provenance improves source recovery and correction propagation relative to an equally large untyped collection of links.

### 13.2 Mountain benchmark

Prepare three interfaces over the same evidence corpus:

1. raw search;
2. one flat summary;
3. hierarchical Mountain summary with descent links.

Test fixed factual/interpretive questions.

Measure answer accuracy, source recovery time, citation precision, contradiction discovery and uncertainty calibration.

**Hypothesis:** hierarchical compression reduces navigation cost without materially reducing source fidelity.

### 13.3 Garden/Farm perturbation experiment

Choose a real graph—repository contributors, institutional dependencies, economic suppliers or another appropriate system.

Measure normal output and then simulate/remove/degrade the central node or support edge.

Compare:

- residual capability;
- recovery time;
- service continuity;
- portability;
- center capture;
- harm/constraint violations.

**Hypothesis:** Garden-like intervention increases capability that survives reduced support.

### 13.4 Spudlight information experiment

Choose **one** layer rather than mixing all of them.

For an archive-information experiment, compare source presentation formats and measure:

- evidence recovery;
- posterior/answer changes;
- information gain;
- source misidentification;
- attention/dwell time separately.

**Hypothesis:** formats can increase information gain without maximizing attention, and vice versa.

### 13.5 Celestial Axis calculator

Implement reproducible transformations using standard astrometry libraries/standards.

Inputs:

- object catalog IDs;
- frame/epoch;
- claimed Axis definition;
- observer/time where needed;
- tolerance.

Outputs:

- transformed vectors;
- angular residuals;
- uncertainties;
- null proximity probability;
- search/multiple-comparison metadata.

**Hypothesis:** explicit frames will resolve many apparent celestial correspondences into either precise alignments or clean symbolic-only relations.

### 13.6 Potato Axis model comparison

Given a predeclared dataset mapping observations to \((r,\theta)\), compare:

\[
M_0: r=R,
\]

\[
M_1:r=a+c\theta,
\]

\[
M_2:r=ae^{b\theta},
\]

\[
M_3:r=ae^{(2\ln\phi/\pi)\theta}.
\]

Use held-out prediction or a declared information criterion rather than visual fit alone.

**Strong result:** the fixed-golden model predicts new points competitively without tuning \(b\).

**Weak/negative result:** the free logarithmic, Archimedean or circular model predicts better.

Both belong in the archive.

## 14. What the scientific programme now says about the project

The scientific layer increasingly supports a structural interpretation of the Potatoverse rather than a hidden-substance interpretation.

The strongest reusable objects are:

- **Relation** — measurable coupling/edge rather than identity by association;
- **Boundary** — selective interface with costs and passages;
- **Door** — guarded change of regime;
- **Axis** — declared orientation/generator;
- **Eye** — observation and inference under uncertainty;
- **Spiral** — recurrence with explicit changed coordinates;
- **Center** — a relational/collective coordinate whose effect can be tested;
- **Garden** — control policy judged by durable capability and viability;
- **Mountain** — compression judged by relevance and provenance;
- **Tree** — differentiation judged by inherited capability and root traceability;
- **House** — bounded plurality judged by protection, exchange and exit;
- **Seed/Potato** — compressed state judged by what generative structure it can reproduce.

This does not scientifically prove Father, Son, Spirit, North-of-North, Spudlight or other theological claims. It does give those concepts a much richer formal neighborhood: instead of merely collecting analogies, the project can state what relation is being compared and what measurement would make the comparison useful or fail.

The scientific programme can now be summarized as one cycle:

\[
\boxed{
\text{Source}
\rightarrow
\text{Signal/Relation}
\rightarrow
\text{Observation}
\rightarrow
\text{Inference}
\rightarrow
\text{Door}
\rightarrow

\rightarrow
\text{Seed}
\rightarrow
\text{Tree Expansion}
\rightarrow
\text{Distributed Capability}
\rightarrow
\text{New Observations}
}
\]

with an Axis specifying orientation/level and boundaries specifying which exchanges are admissible.

For science, every arrow is a demand:

- define the map;
- define the units;
- define the uncertainty;
- define what is preserved;
- define what is lost;
- define the baseline;
- define how to observe the result;
- define what would make the arrow fail.

That is the difference between a diagram full of suggestive equations and a research architecture.
