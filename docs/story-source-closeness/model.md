# Story Source-Closeness Model

Event distance: direct contemporaneous; contemporaneous compilation; later first-person retelling; project reconstruction; archive synthesis.

Editorial distance: raw source; selected extract; structured scene packet; source-near reconstruction; public Story edit; synthesis from prior synthesis.

Continuity: isolated phrase; phrase cluster; partial exchange; contiguous exchange; full session or thread; artifact plus context; complete literary scene.

Closeness is descriptive, not a truth score. Prefer the closest surviving source when it can still be recovered. Unregistered stories remain unmapped rather than receiving invented source relationships.
