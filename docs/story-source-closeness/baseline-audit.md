# Story Source-Closeness Baseline

Date: 2026-09-15

This snapshot records the starting state before broad source-near migration.

- Public Story entries: about 120.
- Entries currently represented in `story-registry.json`: 15.
- Public entries not yet source-mapped through the registry: about 105.
- Registered entries with direct or near-direct source classes: 6.
- Registered entries that already carry a closer-source recovery target: 10.
- Source-near reconstruction examples committed in this wave: one direct-source literary example and one incomplete-source documentary example.

The key baseline is not that 105 stories are bad. It is that their source distance is not yet machine-visible. The audit script now exposes that distinction instead of silently treating every public Story as equally close to source.

Priority after this baseline: recover contiguous source neighborhoods for the highest-value documentary stories before rewriting their public prose.
