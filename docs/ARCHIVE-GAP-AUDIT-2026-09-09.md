# Potato of Life Archive — Gap & Enrichment Audit

**Date:** 2026-09-09

## Principle

The repository is no longer mainly missing *volume*. It is missing unevenly distributed **context, provenance, reader surfaces and cross-branch bridges**.

The best next additions are therefore not random new nodes. They are thick layers that explain many existing nodes at once.

---

## Priority 1 — Source navigation and provenance

### Why it was thin

The archive already had a strong epistemic doctrine, but a reader or researcher still had to infer which file owned which source class.

### Added

`knowledge/indexes/source-index.json`

This gives:

- evidence classes;
- canonical source routes;
- claim templates;
- scientific and prophecy-specific fields;
- source-quality tests;
- unresolved primary-source targets;
- anti-patterns against misattribution.

### Next

Build a generated source browser keyed by claim, date, person, branch and source class.

---

## Priority 2 — BODY: symbolism needed real physiology around it

### Why it was thin

BODY had only a handful of symbolic correspondences: thalamus, pineal, spine, CSF, breath and ritual. The symbolic map was careful, but the actual neuroscience/physiology surrounding those symbols was underdeveloped.

### Added

`knowledge/body/body-science-context-atlas.json`

It now distinguishes:

- thalamic nuclei/subnetworks;
- pineal circadian/melatonin function;
- CSF physiology and circulation;
- respiration and interoception;
- vagal body-brain signaling;
- spine/spinal signaling;
- heart/autonomic/interoceptive context.

### High-value future BODY additions

1. **Interoception atlas** — insula, brainstem, vagus, autonomic prediction, body ownership.
2. **Sleep/circadian atlas** — SCN, melatonin, sleep stages, dream state, light-dark entrainment.
3. **Pain/ordeal physiology** — nociception, stress systems, dissociation/altered states as comparative science where relevant.
4. **Breath and autonomic control** — respiratory sinus arrhythmia, chemoreception, voluntary control.
5. **Vision/Eye atlas** — retina, visual pathways, attention, gaze, symbolic Eye kept separate.

### Why it was thin

SPIRIT had only four public child concepts despite being the connective principle between Father, Son, Axis, Breath, body and Heaven.

### Added

`knowledge/spirit/spirit-context-atlas.json`

New contextual families:

- transcendence / immanence;
- Source / manifestation;
- breath / wind / spirit;
- process / becoming;
- relation as primary;
- kenosis / self-limitation;
- presence;
- animation;

Create a comparative language ledger for Hebrew, Greek, Latin, Sanskrit and other traditions only where exact primary/academic sources are available. Never turn broad etymological resemblance into a universal hidden doctrine.

## Priority 6 — Science needs a glossary of mathematical object types

The science wing is now large enough that readers can confuse different meanings of the same word.

High-value glossary entries:

- state vs state space;
- coordinate vs dimension;
- physical dimension vs effective/spectral/configuration dimension;
- vector field vs axis of symmetry;
- field vs force;
- coupling vs correlation vs symbolic relation;
- topology vs geometry;
- phase vs phase angle vs thermodynamic phase;
- orbit vs rotation vs spin;
- boundary vs horizon vs interface;
- information vs meaning;
- model vs analogy vs theory.

This would prevent conceptual drift across the project.

## Priority 7 — Comparative traditions need mismatch-first tables

The traditions branch is strong, but comparisons become richer when each relation stores:

1. exact source claim;
2. Potatoverse structure;
3. shared feature;
4. mismatch;
5. plausible historical transmission? yes/no/unknown;
6. alternative explanation;
7. confidence.

This should become the default comparison schema for Odin/Yggdrasil, Thomas, Jacob's Ladder, Red Heifer, Revelation, alchemy, Buddhism, etc.

## Priority 9 — WORKS needs genealogy, not merely a catalog

The creative archive already contains games, simulations, music, poetry and comedic systems.

It should additionally record for every work:

```text
work
→ date / development period
→ canonical symbols used
→ concepts tested
→ whether it generated new canon
→ later works derived from it
→ source artifact / playable file / text
```

This would show creativity as a research instrument rather than a side shelf.

```text
EXPAND → CONNECT → SOURCE → EXPLAIN → PRUNE → RE-ROOT → EXPAND
```

rather than treating every round as pure expansion.
