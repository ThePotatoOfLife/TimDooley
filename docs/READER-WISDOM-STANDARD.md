# Reader Wisdom Standard

**Purpose:** make every serious public page in the Potato House useful to a curious human being, not only complete as an archive object.

This standard is editorial, not mechanical. A page does not need every pattern below. It should earn the reader's time by doing the jobs appropriate to its subject.

## The reader-facing test

A strong page should answer four questions before it ends:

1. **What is this?**  
   Give the reader the literal subject, not only its place in the House.

2. **What does it help me understand?**  
   Explain the mechanism, relationship, history, structure or problem in plain language.

3. **Why should a human care?**  
   Connect the knowledge to judgment, conduct, perception, memory, capability, wonder or consequence.

4. **What should I carry away?**  
   Leave one usable distinction, question, method, image or rule that can survive after the page is closed.

## Four layers of a mature Room

### 1. Ground

Facts, definitions, sources, chronology, mechanisms and uncertainty.

A page that has only this layer can be correct but feel like notes.

### 2. Shape

Show how the facts relate.

Use a worked example, sequence, comparison, causal chain, scene, pathway, failure case or counterexample.

A reader should be able to say not only “I learned three facts,” but “I see how the thing works.”

### 3. Human meaning

Ask what the subject changes in ordinary perception or conduct.

Examples:

- anatomy can teach humility about single-center explanations;
- infrastructure can teach respect for maintenance and invisible dependence;
- provenance can teach fairness toward memory while still grading claims;
- literature can show why embodied stories outlive abstract rules;
- geography can teach that the representation must match the question;
- model testing can teach that a trustworthy theory is allowed to lose territory.

This is not permission to manufacture morals. The human meaning must grow from the subject.

### 4. Return

End with a portable tool.

Good return forms include:

- a question to ask;
- a four-step method;
- a distinction that prevents error;
- a compact rule;
- an open problem;
- a next Room that genuinely deepens the same question.

## Write for a person before writing for the archive

Prefer:

> A sincere memory can be valuable before it is exact.

before:

> Source-memory confidence and attestation precision are distinct epistemic fields.

Technical language can follow once the reader knows why the distinction matters.

Prefer concrete nouns and verbs. Let the abstract term arrive after the scene whenever possible.

## Wisdom without sermonizing

A page becomes wiser when it improves judgment, not when it sounds solemn.

Useful forms:

- “The honest map is the one whose geometry matches the question.”
- “A real test can cost the theory something.”
- “Verification is how trust survives time.”
- “A good Gardener should be able to become less necessary.”

Avoid adding aphorisms merely for atmosphere. The line should compress an argument already earned by the page.

## Research rule

External research should do at least one of these jobs:

- establish a factual baseline;
- sharpen a mechanism;
- supply a counterexample;
- name a known phenomenon;
- provide a historical object or primary text;
- challenge a project interpretation;
- make a metaphor narrower and more accurate.

Do not add citations as decoration.

Prefer primary institutions, scholarly reviews, primary texts, museum objects, official datasets and high-quality syntheses appropriate to the domain.

## Project interpretation rule

Keep these visibly distinguishable when they coexist:

- observed external fact;
- Tim/project primary statement;
- later project interpretation;
- comparative analogy;
- speculative model;
- creative or mythic expression.

A page can hold all six. Wisdom comes partly from not forcing them into one evidence class.

## The ordinary-life test

For abstract Rooms, ask:

> What would this distinction look like on an ordinary Tuesday?

Examples:

- **Ethics:** can the person disagree, leave, learn and become less dependent?
- **Information ecology:** is the correction as easy to retrieve as the error?
- **Evidence:** can the sentence be walked backward to the object that permits it?
- **Systems:** what breaks when the small connecting edge fails?
- **Genealogy:** can the archive represent genuine change without rewriting the earlier self?
- **Symbolism:** which part of the analogy actually crosses the bridge?

## Carving rules

### Cut or demote

- maintenance prose visible to ordinary readers;
- repeated explanations of House architecture where subject matter should be first;
- generic “explore related records” language;
- cards whose only content is another label;
- repeated boundary disclaimers after the boundary is already clear;
- lists of names that do not teach a relation;
- jargon that arrives before the problem it names.

### Add or strengthen

- a strong opening question;
- one concrete worked example early;
- a “why this matters” turn;
- a memorable counterexample;
- a human reflection section where the subject earns one;
- clear uncertainty;
- source routes that do not force readers into raw JSON unless they want it;
- an ending with intellectual closure rather than only navigation.

## Acceptance question

Before calling a page finished, ask:

> If a thoughtful stranger read only this page, would they leave knowing something true or clearly labeled, seeing one relationship more clearly, and carrying one better question into the rest of their life?

If the answer is only “they would know where the files are,” the Room is not finished.
