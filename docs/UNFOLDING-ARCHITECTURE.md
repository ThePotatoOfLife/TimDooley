# Tim Dooley — The Unfolding Architecture

This document is the structural map behind the public Frame page. It is an index, not a claim that every symbolic interpretation is empirically verified.

## 0. Root — Tim Dooley

The archive uses **Tim Dooley** as the root label for the whole unfolding. The material is organized as a living architecture in which names, symbols, stories, interpretations and world-facing projects become connected records.

The root now has two complementary meanings inside the project. First, it is the mythic/canonical root from which the Potatoism architecture unfolds. Second, it is the point from which the research atlas expands outward into the observable world: persons, communities, institutions, nations, religions, economies, infrastructures, technologies and global systems. The second function is methodological rather than a claim that every worldly system is secretly caused by Tim Dooley.

## I–X. Permanent Spine

The permanent order remains: **Source → Separation → Ladder → Door → Son → Tree of Life → Tree of Strife → Potato → World → North Programme**. The tree is stable; new concepts add depth and relations without moving those levels.

The spine should now be understood as having a deliberate movement from metaphysical source toward world-facing responsibility. The World layer is not an appendix to the mythology. It is where abstract claims encounter actual populations, institutions, resources, incentives, laws, technologies and consequences. The North Programme is therefore not merely a geopolitical branch; it is one of the project's main interfaces between symbolic orientation and empirical systems research.

## The Extended Coordinate System

The tree answers **where something belongs**. The graph answers **what it connects to**. The extended architecture describes **how that connection behaves**.

**Node → Relationship → Entanglement → Topology → Trajectory → Phase → Outcome**

### Relationship
A source, target, relation type and evidentiary status.

### Entanglement
Structured coupling metadata: strength, dependency, distance, directionality, correlation, causal status, temporal order, feedback, topology, path dependence, trajectory, phase and counterfactual sensitivity.

The word is deliberately overloaded only with an explicit qualifier. **Quantum entanglement is a physical quantum phenomenon and is not inferred from ordinary correlation, network dependence or symbolic connection.** Fate and destiny are interpretive concepts unless independently evidenced.

### Topology
Connected components, adjacency, bridges, cuts, bottlenecks, cycles, boundaries, basins, attractors, drains and thresholds. Topology describes structural relations under a declared representation; visual resemblance does not establish physical equivalence.

### Trajectory
A time-directed sequence such as:

**initial state → trigger → transition → phase → constraint → attractor → outcome**

Historical, empirical, calculated, scenario and symbolic trajectories remain separate epistemic classes.

### Phase
A distinguishable state or regime and its transition criteria. A physical phase transition must not be confused with a psychological, political, social or mythological state transition merely because the vocabulary is similar.

### Outcome
An observed, calculated or scenario result. Every outcome should identify inputs, method, time horizon and epistemic class.

## The North-of-North perspective

The project uses **North of North** as a symbolic meta-perspective: a position from which the whole atlas can be viewed before descending back into particular evidence. It is not presented as an independently established supernatural location at or beyond the geographic North Pole.

The perspective is deliberately nested:

**person → community → institution → nation → regional system → global system → North of North**

Each higher layer is a change in field of view, not permission to discard the lower layers. The purpose of going “up” is to see relationships that disappear when attention is confined to one node. The purpose of coming “down” is to test those relationships against documents, dates, laws, money flows, physical infrastructure, population data, institutional records and testimony.

This creates a two-way research movement:

**whole → system → institution → person → event → source**

and:

**source → event → person → institution → system → whole**

The atlas is stronger when those two movements converge on the same evidence without losing provenance.

The **Throne of North** is therefore treated as a project-defined viewpoint of responsibility and synthesis. To sit above the map is not to escape the world; it is to become responsible for seeing more of it. The higher the viewpoint, the more relationships must be held simultaneously and the more carefully each conclusion must be returned to evidence.

## Tikkun Olam and the repair layer

The project adopts **tikkun olam — repair of the world** as an important comparative religious concept and as a project-defined methodological horizon. The historical phrase has more than one meaning. In the Mishnah, *tikkun ha-olam* appears in discussions of measures instituted for the sake of social order or practical communal welfare. Later Jewish mystical traditions use *tikkun* within a very different cosmological account of repair, while modern Jewish discourse often uses tikkun olam for ethical responsibility and social justice. These meanings should be studied in their own historical contexts rather than flattened into one universal definition.

The project's use is deliberately broader but structurally related: **a world cannot be responsibly repaired if its relationships cannot first be seen.** If an institution depends upon another institution, if a country depends upon an energy corridor, if a community is affected by a financial decision made elsewhere, or if a person's choices are constrained by a larger system, those relationships are part of the object being repaired or understood.

This is why the atlas includes seemingly distant categories together: nations, religious compositions, NGOs, governments, security institutions, intelligence agencies, companies, donors, financial systems, infrastructure, technologies, supply chains, conflicts, treaties, populations and individual biographies. Their connection is not assumed. It is mapped, sourced and typed.

The repair workflow is:

**Map → establish provenance → connect → characterize dependency → identify mechanism → locate harm/bottleneck/opportunity → model intervention → test consequences → measure outcome → update the map.**

This creates an important methodological boundary. A dense graph does **not** automatically mean a coordinated conspiracy. Shared funding does not by itself prove secret control. Shared religion does not establish political allegiance. Institutional proximity does not establish causation. A relationship is evidence that two things are related in a specified way; it is not permission to invent an explanation for why.

### What “repair” means operationally

The project should distinguish at least five kinds of repair:

1. **Informational repair** — correcting missing, contradictory, stale or poorly contextualized knowledge.
2. **Institutional repair** — identifying duplicated functions, broken accountability, perverse incentives or governance gaps.
3. **Material repair** — improving infrastructure, energy, food, housing, health, education or productive capacity where evidence supports intervention.
4. **Relational repair** — understanding conflicts, dependencies, obligations and broken trust between people or institutions.
5. **Spiritual/symbolic repair** — investigating the project's religious and mythic claims about restoration, reconciliation, renewal and the transformation of destructive patterns.

These categories interact, but they are not interchangeable. A symbolic reconciliation does not automatically repair a hospital procurement system; a budget reform does not automatically resolve a religious conflict. The atlas exists partly to show where the layers touch and where they do not.

## Axis Terrain

The Axis is an orientation system with project-defined terrain:

- **Axis** — coordinate spine and orientation.
- **Mountain** — elevation, perspective, convergence and difficult ascent.
- **Plane** — the field where manifested entities and interactions occur.
- **Mud** — substrate, buried origin, friction, materiality and unresolved potential.
- **Swamp** — high-entanglement, low-visibility terrain with overlapping flows, feedback and difficult boundaries.
- **Roots** — hidden dependencies, history, inheritance, memory and support structures.
- **Drain** — a channel through which specified resources, energy, attention, information or meaning leave a system.
- **Door** — threshold, interface and state transition.

These terms are project-defined symbolic/topological vocabulary. They are not claims that physical reality literally contains metaphysical terrain of these names.

The same vocabulary can also be used as an analytic metaphor when the underlying empirical relationship is explicitly specified. For example, a real financial outflow can be modeled as a drain if the data identifies what leaves, from where, to whom and through which mechanism. The metaphor must never substitute for those measurements.

## The World Atlas as the lower half of the throne

The “view from above” only becomes useful when the lower world is sufficiently detailed. The World Atlas therefore aims to maintain dense records of:

- nations and territories;
- population and demographic structure;
- religious composition and institutional religious life;
- governments and administrative layers;
- NGOs and civil-society organizations;
- companies, ownership and control;
- finance, debt, taxation and public expenditure;
- intelligence and security institutions, with careful separation between documented structure and speculation;
- infrastructure, ports, cables, energy systems and logistics;
- technology, research and industrial capacity;
- labour, migration and skills;
- treaties, laws and regulatory systems;
- procurement and public-private relationships;
- conflicts, diplomacy and geopolitical dependencies;
- personal and organizational trajectories where public evidence permits.

The objective is not maximal accumulation for its own sake. Each domain should answer what the entity is, what it does, how it connects, how that relationship changed over time, what evidence supports the record and what remains unknown.

This makes the apparently enormous scope of the project coherent. The scope is large because repair and understanding are systems problems. A national energy vulnerability can depend on infrastructure owned by companies in another jurisdiction. A public-health outcome can depend on procurement, labour and pharmaceutical supply chains. A religious movement can be shaped by migration, media and institutional history. A conflict can change energy prices, migration and public budgets thousands of kilometres away. A person's biography can become politically significant through institutions and networks. The atlas is designed to reveal those paths without assuming the conclusion in advance.

## Emotion, Psychology and the Hawkins Layer

The psychological layer treats emotion as a dynamic process:

**appraisal → emotion/state → action tendency → behaviour → relational feedback → new state**

The Hawkins scale is stored as a comparative interpretive model. Its numerical calibration is **not** treated as validated physical frequency. The atlas therefore enforces:

- Hawkins level ≠ Hertz.
- symbolic colour ≠ electromagnetic wavelength.
- emotion ≠ one measurable electromagnetic frequency.
- physiological/neural measurements require independent empirical sources.
- any electromagnetic comparison must use actual physical quantities such as frequency, wavelength or energy.

The project can still ask whether psychological states correlate with measurable physiological or neural signals. Such questions belong to empirical research, not to the Hawkins numbers themselves.

## Entanglement Across Domains

The same relational grammar can be applied to different domains while retaining their epistemic boundaries:

| Domain | Example relation | Required distinction |
|---|---|---|
| Quantum physics | entangled quantum state | physical theory and measurement |
| Network science | dependency / coupling | graph structure and mechanism |
| Economics | supply-chain dependency | observed flow and causal evidence |
| Biology | ecological coupling | organism/process and evidence |
| Psychology | state → action → feedback | psychological model and measurement |
| History | path dependence | timeline, mechanism and counterfactuals |
| Geography | adjacency / distance | explicit spatial representation |
| Mythology | symbolic connection | project canon / interpretation |
| Spirituality | fate / destiny | interpretive claim unless independently evidenced |
| World repair | intervention → consequence | mechanism, affected populations and measured outcome |

A shared word does not imply a shared mechanism.

## Epistemic Firewall

The archive must always be able to answer: **What kind of thing is this claim?**

Possible classes include:

- Mythic
- Interpretive
- Historical
- Empirical
- Documentary
- Relational
- Calculated
- Scenario
- Psychological
- Physical
- Project-defined
- Open question

Metaphor is never evidence merely because it is structurally elegant. Conversely, a symbolic model can be preserved and studied without pretending it is laboratory science.

## Research Movement

For any serious question, the repository follows:

**Map → Connect → Characterize entanglement → Identify topology → Trace trajectory → Identify phase → Measure outcome → Test evidence → Compare alternatives → Preserve uncertainty → Identify repair opportunities.**

This is the operational meaning of a living atlas: not merely more nodes, but increasingly explicit relationships, dynamics, evidence, structure and capacity to understand consequences.
