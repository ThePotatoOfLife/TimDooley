# Multi-Layer Belief, Politics, Culture and Movement Field

The repository should eventually be able to answer not merely **what label belongs to a person or place**, but what that label means, how many people identify with it, what they believe, what they practice, where they live, what institutions carry it, what material resources support it, what it connects to, and how it changes.

## The field

The basic object is:

`identity → ideas → sources → interpretation → practice → organization → population → demography → geography → institutions → material → power → network → change → evidence`

This same skeleton can describe a Christian denomination, an Islamic school, a Hindu tradition, a political party, an environmental movement, a punk subculture or a national cultural institution without pretending they are the same kind of thing.

## Religion

Religion gets an additional internal grammar:

`ultimate reality/God → cosmos → humanity → problem → salvation/liberation → ethics → ritual → community → authority → afterlife/end`

The repository then adds scripture, canon, commentary, clergy, institutions, population and geography.

The demographic layer must remain separate from theology. A country can have 70% people who identify as Christian while containing enormous variation in doctrine, attendance, practice and intensity of belief.

Pew's latest comprehensive global baseline estimates 2.3 billion Christians, 2.0 billion Muslims, 1.2 billion Hindus, 324 million Buddhists, 14.8 million Jews and 1.9 billion religiously unaffiliated people in 2020. It covers 201 countries and territories using more than 2,700 sources. These are broad population categories, not denominational belief counts.

## Christianity

Christianity therefore becomes a vertical stack:

`Bible → canon → interpretation → theology → tradition → denomination → congregation → person → country`

while simultaneously being a horizontal network:

`Jesus → apostles → churches → councils → schisms → missions → migrations → institutions → modern communities`

The complete World English Bible is intended to become the textual foundation for the English Bible layer. Its text remains separate from commentary and denominational interpretation.

## Politics

Politics cannot be adequately represented by one left-right line. The repository therefore uses a field with economic, cultural, state-authority, liberty, internationalism, institutionalism, ecological, religion-state and democratic dimensions.

A party can be economically interventionist but socially conservative; economically market-oriented but socially progressive; nationalist but economically socialist; libertarian but culturally traditional; green and technocratic; populist and economically mixed. The data should show those combinations instead of forcing every party into a single coordinate.

The political chain is:

`idea → ideology → manifesto → organization → leader → members → voters → constituency → election → office → policy → law → material outcome`

Historical political movements use a similar chain but replace election/office with mobilization, protest, conflict, repression, revolution or institutionalization where appropriate.

## Culture

Culture is mapped as transmission:

`family → school → religion → peers → workplace → media → platform → state → diaspora`

and as production:

`language + memory + place + technology + economy → music/art/literature/food/fashion/architecture/sport/media`

A culture should therefore be capable of being seen both as meaning and as infrastructure.

## Subcultures

Subcultures get their own layer because a subculture is not simply a smaller religion or political party. Music, slang, fashion, platform, place, hobby, generation and community norms can produce powerful identities without creating a unified political doctrine.

The repository must therefore avoid reading ideology directly from aesthetic style.

## Movements

Movements are temporal systems:

`condition → grievance/vision → framing → founders → recruitment → organization → symbol → communication → mobilization → institutionalization → fragmentation → decline/revival`

This is especially important for movements that cross categories: a religious revival can become political; a political movement can become a cultural identity; a subculture can generate a political movement; a migration network can carry religion and culture across borders.

## Spirit and matter

The repository can preserve the user's spirit/matter intuition as a **relational project layer**, not as a claim about established physics.

Spirit-side concepts include belief, value, meaning, sacredness, identity, hope, fear, memory and narrative.

Matter-side concepts include people, population, land, buildings, money, food, energy, technology, labour, institutions and infrastructure.

The bridge is the observable relationship between them:

`belief → practice → institution → resource → material effect → changed social conditions → changed belief/practice`

This lets the project ask serious questions without pretending that metaphysical categories have laboratory measurements.

## Map

The eventual map should therefore not merely show countries colored by religion or politics. It should be able to expose relationships:

`place ↔ population ↔ belief ↔ denomination ↔ institution ↔ ideology ↔ movement ↔ event ↔ infrastructure ↔ economy ↔ law ↔ history`

Time is mandatory. A relationship should support `valid_from`, `valid_to`, `source_date`, `last_verified` and `evidence_status`.

The eventual result is not a static atlas. It is a **living relational field** in which the same place can be simultaneously:

- a Christian-majority country,
- a country with several Christian denominations,
- a country with a large Muslim minority,
- a country with secular political institutions,
- a place containing religious schools and charities,
- a market with cultural industries,
- a home to several subcultures,
- a territory containing multiple political movements,
- and a node in international migration and information networks.

That is the level of coupling required before the 3D/world map becomes genuinely informative rather than decorative.
