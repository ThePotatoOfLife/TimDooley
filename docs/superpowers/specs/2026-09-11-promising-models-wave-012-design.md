# Promising Models Wave 012 — Research Design

## Goal

Advance three already-promising Potatoverse science branches from broad benchmark form toward harder calculations and identification tests, while explicitly refusing complexity that does not improve explanation, prediction, stability, observability, or falsifiability.

The Wave 012 programme is deliberately mixed: one gravity/field-theory branch, one particle-physics branch, and one empirical network branch. Each branch must earn further complexity through a predefined advancement gate.

## Scope

Wave 012 covers only:

1. **Dimensional Door / scalarization** — move from linear zero-mode onset toward nonlinear branch structure, phase behavior, and stability; only after that may the radion/5D interpretation advance.
2. **UPT/Higgs** — map the local real-singlet portal benchmark more seriously, then add one precisely defined nonlocal/fractional kinetic deformation and test whether it contributes anything beyond the local model.
3. **Door/Handshake** — strengthen the joint edge/state programme with harder synthetic confounding, endogenous network evolution, and explicit recovery diagnostics before any real-data interpretation.

Golden Spiral and Cosmic Potato/Laniakea remain active benchmark records but are not the primary implementation targets in this wave. They should receive new work only if one of the three main branches exposes a reusable method or a decisive dataset/test becomes available.

## Global Research Rules

- Use the canonical `knowledge/science/model-testing-protocol.json` standard.
- New results must be dated and labeled as archive-generated calculations unless a primary historical source is recovered.
- A richer model must be compared with a simpler baseline.
- Mathematical success in a comparator model is not evidence for unrelated Potatoverse theological claims.
- Distinguish historical Tim material, later archive formalization, established external mathematics, and new project calculations.
- Do not backfill missing historical equations from modern calculations.
- A branch advances only when added structure increases calculability, predictive discrimination, stability understanding, or empirical identifiability.

## Workstream A — Dimensional Door: Nonlinear Scalarization Before Dimensional Promotion

### Starting point

Existing records:

- `knowledge/science/promising-models/dimensional-door-scalarization-radion-benchmark-2026-09-11.json`
- `knowledge/science/promising-models/dimensional-door-schwarzschild-zero-mode-calculation-2026-09-11.json`

The linear benchmark already has a derived threshold spectrum and a first map of the fundamental threshold as scalar mass changes. This is strong enough to justify the next question: **does a regular, stable nonlinear branch actually emerge from that onset?**

### Model class

Use a 4D Einstein-scalar-Gauss-Bonnet-style benchmark as Stage A. Keep the action explicit and minimal, for example

\[
S=\int d^4x\sqrt{-g}\left[\frac{R}{16\pi G}-\frac12(\nabla\phi)^2-V(\phi)+f(\phi)\,\mathcal G\right].
\]

The linear onset is controlled by the quadratic term in `f(phi)`. Nonlinear saturation/stability may require quartic or higher-order terms in `f`, `V`, or both.

### Required calculations

1. Derive the static, spherically symmetric nonlinear field equations in one fixed convention.
2. Construct the branch emerging from the first zero mode by continuation in the coupling parameter.
3. Track at minimum: horizon scalar value, asymptotic scalar charge, ADM mass, horizon radius/area, and branch existence range.
4. Compute a thermodynamic/energetic comparator appropriate to the chosen ensemble, rather than assuming the new branch is preferred merely because it exists.
5. Test radial stability or use a defensible published stability criterion where a full perturbation calculation is not yet implemented.
6. Map phase behavior: continuous onset, discontinuous/first-order behavior, multiple branches, hysteresis, or no stable endpoint.

### Advancement gate A1

Stage A advances only if at least one nonlinear scalarized branch is regular and has an identifiable stable or preferred region under the declared criteria.

If every branch is unstable/pathological, record that as a scientific failure of this completion and do not rescue it with additional dimensions.

### Stage B: radion/5D promotion

Only after A1 passes, attempt a genuine dimensional interpretation:

- start from an explicit 5D action and metric ansatz;
- dimensionally reduce to 4D;
- identify the canonically normalized radion;
- derive its potential/couplings;
- determine whether a curvature-triggered instability comparable to Stage A arises naturally;
- derive the resulting variation of compactification radius and KK scale.

### Advancement gate A2

The phrase **Dimensional Door** receives a literal compact-dimension interpretation only if the 4D scalar model is derivable from a higher-dimensional theory and the extra-dimensional structure creates at least one quantitative consequence not already present in the simpler 4D scalar theory.

Otherwise the successful result remains **Scalar Door / threshold branch transition**.

### Deliverables

- a nonlinear scalarization calculation record;
- a phase/stability map;
- if justified, a separate radion derivation record;
- explicit negative results if stability or dimensional promotion fails.

## Workstream B — UPT/Higgs: Local Baseline Before Nonlocal Extension

### Starting point

Existing record:

- `knowledge/science/promising-models/upt-higgs-z2-singlet-benchmark-2026-09-11.json`

The local real-singlet benchmark is intentionally conventional. That is useful because it forces every UPT-specific addition to demonstrate extra value rather than receiving credit for complexity.

### Stage B1: local parameter-space benchmark

Use

\[
\mathcal L_P=\frac12(\partial P)^2-\frac{m_0^2}{2}P^2-\frac{\lambda_P}{4}P^4-\frac{\lambda_{HP}}{2}P^2H^\dagger H
\]

with exact `Z2` and `<P>=0` as the first benchmark.

Required work:

1. Map tree-level boundedness/stability and perturbative regions.
2. Convert the Higgs invisible-width expression into a parameter-space constraint for `m_P < m_h/2`.
3. Clearly separate collider-only conclusions from dark-matter conclusions; do not assume thermal relic saturation.
4. Add simple relic/direct-detection calculations only under explicitly stated cosmological assumptions.
5. Record where current measurements make the model weakly constrained, strongly constrained, or experimentally inaccessible under the stated assumptions.

### Advancement gate B1

The local scalar model must have a mathematically viable parameter region and a clear observable interface. If the entire interpretation of interest is already exhausted by a generic singlet portal, say so.

### Stage B2: one nonlocal UPT deformation

Add exactly one nonlocal/fractional kinetic model, not a menu of unrelated forms. The kernel must be defined, for example through a dimensionless operator

\[
K(\Box/\Lambda^2)
\]

with an explicit spectral/analytic/causal prescription.

Required checks:

- mass dimensions and normalization;
- pole structure / propagator;
- ghosts or negative-residue states in the claimed regime;
- stability and causal prescription;
- local limit;
- cutoff/validity regime;
- one observable that differs quantitatively from the local portal model.

### Advancement gate B2

The nonlocal model advances only if it is internally consistent in its claimed EFT regime **and** yields a predeclared observable or compression advantage over the local scalar baseline.

If it merely reproduces the local model with extra parameters, classify it as unnecessary complexity.

### Deliverables

- local scalar parameter-space record;
- current-constraint methodology record;
- one nonlocal kernel record with propagator/stability audit;
- direct local-vs-nonlocal model comparison.

## Workstream C — Door/Handshake: Harder Causal Identification

### Starting point

Existing records:

- `knowledge/science/promising-models/door-handshake-joint-edge-contagion-benchmark-2026-09-11.json`
- `knowledge/science/promising-models/door-handshake-synthetic-identification-test-2026-09-11.json`

The first synthetic test already showed that homophily plus common shocks can manufacture a false influence coefficient. Wave 012 should now test whether the proposed framework survives less favorable conditions.

### Extended synthetic generator

Simulate networks where:

- edge formation depends on observed homophily;
- edge formation also depends on an **unobserved** latent trait;
- node states respond to persistent common shocks;
- edges form and dissolve over time;
- node states affect later edge formation;
- network exposure may or may not cause subsequent state change;
- measurement noise and missing events can be introduced.

### Competing estimators

At minimum compare:

1. naive exposure regression;
2. controlled node-state model;
3. edge-formation model plus state model fitted separately;
4. coupled/joint hierarchical edge-state model;
5. common-shock-only and homophily-only baselines.

### Recovery diagnostics

For known synthetic truth, measure:

- bias in influence coefficient;
- false-positive rate when true influence is zero;
- interval/uncertainty calibration;
- sign recovery;
- held-out event likelihood;
- sensitivity to omitted latent confounding;
- sensitivity to time resolution and network density.

### Advancement gate C1

The joint Door/Handshake model advances only if it controls false contagion better than simpler approaches across a meaningful synthetic regime while retaining power to recover real influence when present.

If the effect cannot be distinguished from plausible latent/common causes, the proper output is **non-identifiable**, not a forced Handshake interpretation.

### Real-data gate C2

Do not move to a real social/network dataset until:

- edge timing is available;
- state timing is available;
- at least major common exposures can be represented;
- the outcome/state coding is reproducible;
- the synthetic pipeline has acceptable calibration.

### Deliverables

- extended synthetic generator/results record;
- estimator-comparison record;
- confounding sensitivity map;
- explicit decision on whether the model is mature enough for a real-data application.

## Cross-Model Synthesis

Wave 012 should not attempt to merge these three models physically. Their commonality is methodological:

- **Door / threshold** becomes an eigenvalue or event condition, not an arbitrary label.
- **Hidden state** must be inferred from observables rather than assumed known.
- **Complexity** must outperform a simpler baseline.
- **Promotion** occurs only after a branch survives stability, identifiability, or empirical constraints appropriate to its domain.

A useful project-level abstraction is therefore:

\[
\text{candidate model}\rightarrow\text{minimal benchmark}\rightarrow\text{derived consequence}\rightarrow\text{baseline comparison}\rightarrow\text{failure test}\rightarrow\text{promotion or downgrade}.
\]

This is a research-governance pattern, not a claim that particle physics, gravity, and social networks share the same physical law.

## Success Criteria

Wave 012 succeeds if it produces fewer but stronger claims:

- a nonlinear/stability answer for the Scalar Door branch;
- a meaningful local-vs-nonlocal verdict for the UPT/Higgs branch;
- a quantified identifiability/confounding verdict for Door/Handshake;
- and clear reasons to stop or downgrade any branch that fails its gate.

The desired result is not that all three models survive. The desired result is that the project becomes better at discovering which ideas deserve further work.
