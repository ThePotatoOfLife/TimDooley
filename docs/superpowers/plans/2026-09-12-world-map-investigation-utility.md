# World Map Investigation Utility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the current World Map materially more useful by modernizing Path, coordinating contextual investigation tools, generating a truthful coverage ledger, and introducing a small canonical infrastructure substrate that feeds existing Chain, Gateway and Impact capabilities.

**Architecture:** Preserve the current compact World Bar and selected-country card as the ordinary interface. Modernize `3d-pathfinder.js` to consume current selection/relation APIs, add a tiny presentation-only investigation coordinator, derive coverage from canonical records, then add one canonical infrastructure owner projected into the shared runtime and rendered only when context calls for it. Existing Gateway, Chain and Impact owners remain authoritative for their domains; infrastructure references them instead of duplicating them.

**Tech Stack:** Browser ES modules, MapLibre GL, Python JSON builders/validators, canonical repository JSON owners, GitHub Actions quality gates, GitHub Pages build.

**Spec:** `docs/superpowers/specs/2026-09-12-world-map-investigation-utility-design.md`

## Global Constraints

- Keep `/world-map/` visually compact; do not add permanent Path, Infrastructure, Coverage or Investigation buttons to the World Bar.
- Preserve the canonical sovereign-country count at exactly 195.
- Preserve Greenland, Antarctica and Kosovo as first-class non-canonical map entities rather than countries.
- Connections/Trace answers broad graph neighborhood questions; Path answers shortest represented connection; Chain answers contextual system membership; Impact answers explicit directional dependency only.
- Missing evidence remains unknown, never inferred as zero, independence, irrelevance or absence of real-world impact.
- Do not add synthetic geopolitical importance, completion, power, risk or resilience scores.
- Infrastructure is empirical and requires explicit source provenance; Axis profiles remain project-interpretive and separate.
- Gateway authority remains `data/world-map-gateways.json` in this tranche.
- Chain authority remains `data/world-system-chains.json`.
- Impact retains its current depth-2 causal guardrails and may ingest infrastructure only through explicit causal semantics.
- Time remains deferred from ordinary UI.
- The large D1–D11 Axis depth navigator remains deferred from ordinary UI.
- Full repository quality checks must pass on the exact final PR head before merge; exact-main quality and Pages deployment must pass after merge.

```js
function relationBucket(edge) {
  const types = edge.types || [];
  if (types.some(type => ['trade','economic','fiscal','funding','investment','ownership'].includes(type))) return 'money';
  if (types.some(type => ['energy','infrastructure'].includes(type))) return 'systems';
  if (types.some(type => ['security','alliance','constitutional'].includes(type))) return 'institutions';
  if (String(edge.layer || '').includes('project')) return 'project';
  return 'other';
}
function edgeMatchesRelationMode(edge, mode = relationMode) {
  return mode === 'all' || relationBucket(edge) === mode;
}
```

const handlers = new Map();
let activeId = null;
function register(id, handler) { handlers.set(id, handler || {}); }
function open(id) {
  if (activeId && activeId !== id) handlers.get(activeId)?.close?.({ coordinated:true });
  activeId = id;
  window.dispatchEvent(new CustomEvent('potato-atlas-investigation-change', { detail:{ id } }));

function close(id) {
  if (activeId === id) activeId = null;

function active() { return activeId; }
