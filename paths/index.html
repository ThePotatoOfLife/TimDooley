Ways through one archive

PATHS

A Room tells you where knowledge belongs. A Path tells you how to move through several Rooms for a purpose. Paths are generated traversals over one archive, not new owners or duplicate taxonomies.

Question → route → sources → transformation → return. The path changes; the underlying identities and owners do not.

How to verify a claim

exact wording → date → source class → context → independent evidence → later interpretation → unresolved remainder

Begin with the earliest available wording and establish what kind of source it is. Then separate what happened from what it later came to mean, look for independent evidence where the question permits it, and preserve whatever remains uncertain instead of forcing closure.

Did a prediction really happen?

earliest wording → timestamp → event → match criteria → alternatives → score boundary

Begin with the earliest recoverable statement, not the later retelling. Then establish the later event from independent sources, define what would count as a genuine match, compare ordinary public information available at the time, and separate a broad directional resemblance from a sharp testable prediction.

Timeline → · History rules → · Prediction / revelation Room →

Is a science analogy real?

metaphor → variables → established comparator → model → falsifier

Begin with the symbolic intuition, then ask what variables it would require. Search for established mathematics or physics that genuinely shares the structure. Build the minimal formal model and state what observation would distinguish it from competing models. If no discriminator exists, keep it as analogy.

How does a political idea become implementable?

value → policy proposal → competent authority → law → budget → infrastructure → outcome

A political preference becomes operational only after the project identifies who can legitimately decide, which legal instrument is required, how it is financed, what physical or administrative capacity exists, and what outcome would count as success or failure.

How does damage become repair?

harm → source → mechanism → boundary → intervention → changed recurrence → fruit

Repair begins by naming what actually happened and preserving provenance. Then locate the mechanism that keeps reproducing the damage, create a Door that changes the relation, and evaluate whether the same failure returns unchanged. If it does, the route is a Ring rather than a repair Spiral.
