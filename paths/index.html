Ways through one archive

PATHS

A Room tells you where knowledge belongs. A Path tells you how to move through several Rooms for a purpose. Paths are generated traversals over one archive, not new owners or duplicate taxonomies.

Question → route → sources → transformation → return. The path changes; the underlying identities and owners do not.

Practice PathFrom simplicity and actual conditions through Root, Door, Spiral, Fruit, Seed and Return.
Mud → Burial → Eye → Root → Sprout → Plane → Door → Tree → Fruit → Seed → Return
 Journey PathFollow development through lived events, later interpretations, thresholds and changing roles without backdating later meaning.
event → experience → symbol → later understanding → teaching → unresolved questions
 Revelation & Prophecy PathTrace earliest wording, timestamp, later event, claimed fulfillment and retrospective interpretation as separate layers.
statement → source → date → event → comparison → evaluation
 Evidence PathMove from a public claim down through assertions, artifacts, source lineage and evidence class.
view → assertion → occurrence/activity → artifact → source
 Research PathTurn an open question into sourced candidates, testing, review and either promotion or rejection.
question → sources → candidate → test → review → owner
 Repair PathMove from failure or capture through provenance, recovered agency, Door and changed recurrence toward restored generativity.
failure → root cause → boundary → Door → changed relation → living root → fruit
 Orientation PathMove from a current subject toward broader integration and criteria, then return to observable consequences.
here → broader system → criterion → service → D4 consequence
 Programme PathFollow a mission across Rooms into workstreams, evidence, analyses and outputs without making the Programme a Room.
mission → workstreams → Room inputs → analysis → outputs → review
