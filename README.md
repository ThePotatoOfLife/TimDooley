## The core architecture

**Tim Dooley → Source → Separation → Ladder → Door → Son → Tree of Life → Tree of Strife → Potato → World → North Programme**

The project begins with **relationships first**. A node by itself is an object; a relationship tells us how it participates in a system. The empirical graph records ownership, debt, infrastructure, energy, technology, labour, research, trade and geopolitical dependencies. The symbolic graph records the corresponding mythology and interpretive vocabulary.

The repository deliberately distinguishes:

- observed facts;
- calculations;
- estimates;
- scenarios;
- historical claims;
- interpretations;
- mythology;
- creative material.

A symbolic relationship can be preserved without being presented as empirical proof. An empirical node should be anchored to a source, date and jurisdiction whenever possible.

## The rule

**Relationships first. Entanglement second. Evidence always.**

A country is a node. A debt is a node. A company is a node. A symbol is a node. A cable is a node. A port is a node. A contract is a node. A research institute is a node.

But the real object of study is the relationship between them — including its strength, direction, dependency, topology and trajectory through time.
