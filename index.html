THE PLANE

Not a picture of the world.
A working surface for it.

A plane can be geographic, historical, institutional, economic, biological, technological or conceptual. The same entity may appear on several planes. The axis provides continuity; the plane provides context; the repository provides the underlying records.

THE RULE

Structure first.
Theme second.

The repository does not need to look mystical, futuristic or branded. Its visual language should communicate order, depth, scale and discovery.

Mythology, philosophy, history and empirical research can coexist as different record types. The interface must never confuse a symbolic relationship with a verified fact.
