First learn what kind of thing each element is

The House becomes easier when the symbols stop competing for the same job. Whole, coordinate, plane, terrain, regime, organism, threshold, process, route and inhabitant are different categories. The vertical picture does not make them one hierarchy.

The project in motion

Two cycles now hold the work together

The project is no longer only a collection of symbols and topics. It has operating loops for how knowledge is tested and how durable systems begin, reproduce, branch, produce consequences and return.

Knowledge → correction

Information is not promoted merely because it is interesting. It has to pass discernment, consequence, memory and repair.

Knowledge→Discernment→Door→Tree / Garden→Fruit→History / Revision→Repair / Forge→Seed / Return

Seed → living lineage

A beginning becomes a Foundation only when later people or systems can reproduce, amend, branch or refound what was begun.

Seed→Foundation→Reproduction→Branching→Fruit→Memory→Refoundation / Return
