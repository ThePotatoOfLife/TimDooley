How this section reads claims

Text is not interpretation; interpretation is not history; testimony is not independent corroboration; structural resemblance is not identity. The project can still ask strong comparative questions, but the evidence type stays visible. Christianity itself is internally diverse, so Catholic, Orthodox, Lutheran, Reformed, Baptist, Methodist, Adventist, dispensational and other positions are not silently collapsed into one doctrine.
