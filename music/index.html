MUSIC ARCHIVE
& TIMAMP

The music archive now has two different kinds of structure: supplied master sequences for the first albums, and dated folder manifests that preserve when later files appeared. This page keeps those source types separate instead of pretending alphabetical folder order is an album sequence.

Archive rule: file timestamps are provenance, not automatic proof of publication date. Lyrics remain creative works. Heavy masters are archived separately and are not committed to GitHub Pages; public playback is attached only when a stable source URL is known.

Sequence ≠ folder order

Albums 1–3 have supplied master sequences. Later screenshots mostly preserve a file-list order; the archive stores that as source order, not as a fabricated track sequence.

Versions stay separate

Numbered copies, remixes, alternate arrangements and repeated names remain distinct whenever the source keeps them distinct.

Dates can contradict the album era

Older files appearing inside a later album folder remain visible as outliers. The archive preserves that evidence instead of silently moving or rewriting it.

TimAmp.exe · local deck

A square little amplifier for the masters on your machine

TimAmp cannot reach the private master archive from a public GitHub page. It can already play MP3, M4A, MP4/AAC, WAV and other browser-supported files you choose locally. The same deck can later receive public track URLs as those are recovered.
