How to read this atlas

Click any nation

Every polygon is a doorway into a country node. The page combines live public country/economic data with separately labelled Tim/Potatoverse interpretations and repair questions.

Three layers stay separate: observable facts, project interpretation, and comparative spiritual/theological meaning. A country can overlap multiple systems; no faith or people is assigned collective guilt.

The basic question

What is it → what does it have → what can it do → what does it need → who depends on it → what does it depend on → what can it only do with others → what is it building → where is it going?
