SCIENCE

The project contains several mathematical or scientific model families. Their status differs: some are defined mathematics, some are modelling frameworks, and some are speculative physical proposals.

Formal toy model

Unified Potato Theory

ℒUPT = √−g [ R/(16πG) + ½ P □ᵅ(1+ℓ²/□)P − V(P,r) − ¼Fₚ² + ℒSM + ℒint + ℒGB + ℒCDT ]

A recovered attempt to write a literal physical Potato-sector theory coupled to gravity, Standard Model terms and additional interaction structure.

It is not yet a closed, gauge-consistent physical theory. Field representations, operators, scales and falsifiable predictions remain incomplete.

Defined mathematics

Potato Axis logarithmic spiral

r(θ)=aeᵇᶿ   ·   b=2ln(φ)/π ≈ 0.30635   ·   r(θ+π/2)=φr(θ)

The recovered Axis curve is a logarithmic spiral whose radius scales by the golden ratio after each quarter-turn. The geometry is mathematically well-defined; any physical interpretation requires a separate model and dataset.

Formal framework

Potato Dynamics

𝔓=(𝒮,g,A,𝒟,𝒪,𝓘)   ·   ∂ₜX=F(X,g)   ·   ∂ₛX=A(X,g)

A domain-neutral architecture separating physical/time evolution from structural or scale flow, with Door transitions, observables and information explicitly represented.

Its scientific value depends on concrete instantiations with measurable states, transitions and baselines.

Formal framework

Door / boundary transition model

D=(input, guard, transition, output, invariants, cost, reversibility)

The Door is treated as a transition operator: an input satisfies a guard or boundary condition, crosses a defined map and yields an output while invariants and costs are tracked.

This is strongest as control, inference and hybrid-systems language; retrocausal interpretations require independent evidence.

Candidate model family

Dimensional projection

πd : 𝒫 → Md   ·   M₁₁ → M₄ × X₇

This branch asks how richer or higher-dimensional descriptions project into lower-dimensional effective ones without treating every use of “dimension” as the same claim.

A literal 11-dimensional physical model still needs explicit fields, compactification, scales and predictions.

Information model

Spudlight

Y=HX+N   ·   I(X;Y)=Σ p(x,y) log[p(x,y)/(p(x)p(y))]

Spudlight becomes tractable when photon flux, information gain, attention, social coherence and semantic interpretation are kept as distinct observables.

The strongest scientific version is an information-and-observation model, not evidence for a new electromagnetic force.

Research programme

Cross-scale coupling

𝒞 : ρmicro → Xmacro   ·   Mq̈+Γq̇+Kq=ξ(t)

Similar structures at microscopic, neural, social or astronomical scales do not establish coupling. A serious cross-scale claim requires an explicit projection, coarse-graining or mechanism between scales.
