Five kinds of Return

The archive now distinguishes:

Return = ( endpoint, internal state, phase / holonomy, topology / homotopy class, scale )

This prevents a circular path, a spinor return, a Berry phase, an RG recurrence and a narrative return from being treated as the same phenomenon.

The Door contract

D = ( input domain, activation / guard, transition map, output domain, preserved invariants, cost / dissipation, reversibility class )

Every future Door model should fill these fields. If it cannot, it remains symbolic rather than mathematical.

The celestial audit

C = ( object, epoch, RA, Dec, observer position, date/time, azimuth, altitude, proper motion, source )

This is the new standard for Sirius, Sun, North, pole and precession claims. “Point to Sirius” can become an astronomical question instead of an ambiguous symbol.
