# Potato House — Operator Map

**Status:** research candidate; non-canonical.

The operators below overlap, but should not be treated as synonyms.

| Operator | Core function | Not equivalent to |
|---|---|---|
| Soil | environment, context, conditions | Root, Archive |

| Stolons / Roads | transport, signal, relation, flow | generic adjacency |

## Key corrections from literal potato biology

1. **Potato is not Root.** A tuber is a modified underground stem derived from a stolon.
2. **Role is stateful.** A tuber can be a sink while filling and later a source during sprouting.
3. **Eyes are distributed future points.** One leading sprout can dominate temporarily while other eyes remain viable.
4. **Dormancy is regulated viability, not absence.** Internal readiness and environmental permission are different.
5. **Signals travel.** Local developmental changes can be triggered by long-distance signals.
6. **Genealogy can be reticulate.** Tree is not the only ancestry topology.
7. **Repair is staged.** Temporary closure can precede mature boundary repair.
8. **Continuity carries debt.** High-fidelity copying can preserve burdens as well as capability.

## Vertical grammar

```text
          integration / synthesis / criterion
                         ▲
                      NORTH
                         │
                     MOUNTAIN
                         │
======================= PLANE =======================
      current objects · relations · users · work
                         │
        decomposition · provenance · causes
                         ▼
               roots / buried depth
```

Upper does not mean truer. Lower does not mean worse. Plane is not a folder.

A selected North path can stabilize orientation without pretending reality has only one meaningful parent.

## Interaction laws

- Mountain compresses; Tree differentiates.
- Compression is not fully invertible; reversibility comes from stored identity and provenance.
- Swamp can exist below, on or above the Plane.
- Garden is a viable region, not a score.
- Forge succeeds only if capability survives after pressure ends.
- Spiral is `same identity + memory + changed state`.
- A hyperlink may cross a Door; a hyperlink alone does not define the Door.
