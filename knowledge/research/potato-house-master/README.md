# Potato House Architecture — Master Research Roof

**Status:** master research synthesis; architecture candidate; **not canonical and not a runtime contract**.

## Purpose

This collection gathers the strongest existing Potato of Life architecture, literal potato biology, Potato Dynamics, Root/Plane/Axis geometry, House/Rooms, Archive epistemics, D1–D11 operators, World/Axis navigation, systems-theory research, software architecture lessons, web standards and the failure modes exposed by the recent Atlas experiment into one research roof.

The goal is not to crown another metaphor. The goal is to discover the smallest set of distinctions and operations that survive many domains without flattening them.

> **Working conclusion:** the Potato House is not a folder tree, one graph, one hierarchy or one homepage taxonomy. It is a versioned, stateful, multi-graph, open-system knowledge organism whose durable identities are embedded in context, history, provenance, relations, transitions, interfaces and projections.

`Node + Relation + Artifact + View` remains useful as low-level implementation vocabulary. It is not the governing Potato architecture.

## Why this collection exists

The recent Atlas experiment strengthened useful engineering rules: stable IDs, one current owner per durable concept, typed relations, provenance preservation, reproducible Views, static semantic HTML, validators that do not mutate, CSS ownership and migration compatibility.

The mistake was promoting those primitives into the conceptual architecture. That flattened several existing distinctions:

- one North orientation was treated too much like ontology;
- Mountain and Tree were collapsed into one hierarchy read in opposite directions;
- Rooms were reduced to Views;
- Door drifted toward “hyperlink” rather than guarded state change;
- Archive drifted toward storage rather than living source/memory;
- Potato biology became illustrative rather than corrective;
- backend vocabulary leaked into the public threshold.

This collection exists to recover the deeper system before another runtime architecture is promoted.

## Literal potato biology as architectural constraint

The Potato is not the Root. Botanically, the tuber is a modified underground stem derived from a stolon. Roots, stolons, tubers, eyes, sprouts, leaves, flowers, berries and true seed are different organs/functions.

That gives the project a more disciplined functional grammar:

| Biological structure/process | House function |
|---|---|
| Soil / environment | context, external conditions, audience, jurisdiction, resources |
| Roots | acquisition, grounding, provenance, dependency, uptake |
| Stolons / transport | typed Roads, signaling, transport, dependency flow |
| Potato / tuber | storage, compression, retained capability |
| Eye / meristem | latent local future, observation/retrieval, viable activation point |
| Dormancy | viable regulated non-expression |
| Sprout | activated trajectory |
| Stem / trunk | continuity/support |
| Leaf | sensing/exposure/assimilation |
| True seed | recombinant continuation |
| Daughter tuber | higher-fidelity continuation |
| Periderm / wound periderm | selective boundary and staged repair |
| Fruit / harvest | useful output/nourishment/consequence |

Important biological corrections:

1. **Identity is stateful.** A tuber can be a sink while filling and later a source during sprouting.
2. **One active path need not erase dormant alternatives.** Apical dominance can privilege one sprout while other eyes remain viable.
3. **Dormancy is not absence.** Viability, internal readiness and external conditions differ.
4. **Local development can be triggered by distant signals.** Tuberization depends on long-distance signaling toward stolon tips.
5. **Genealogy is not always a tree.** Recent potato-evolution work supports ancient mixed ancestry in the Petota lineage.
6. **Repair is staged.** Wound closure and mature periderm formation suggest temporary compatibility tissue followed by a mature interface.
7. **Clonal continuity preserves burdens as well as capability.** Faithful copying can reproduce defects.
8. **Context has memory.** Environmental history can influence later expression.

## Upper / Plane / lower ordering

The Root System geometry supplies ordering rather than literal folders:

```text
                  UPPER FIELD
       criterion · synthesis · integration
                        ▲
                     NORTH
                        │
                    MOUNTAIN
                        │
====================== PLANE ======================
 current objects · relations · users · events · work
                        │
         decomposition · provenance · causes
                        ▼
                  LOWER FIELD
```

Rules:

- upper does not mean truer, holier or morally superior;
- lower does not mean worse;
- Plane is the operative/contact state;
- compression upward and reconstruction downward are not symmetric operations;
- one selected North path may orient navigation without pretending reality has one ontological parent;
- Swamp can distort the Plane from below, within it or through bad synthesis above it;
- Mountain and Swamp are not opposites: Mountain compresses while preserving orientation/path-back; Swamp entangles without adequate distinction, metabolism or exit.

## House as a family of coordinated structures

A stronger conceptual decomposition is:

`H = (V, X, C, T_N, E_B, E_R, E_P, E_T, E_A, E_D, E_F, A, Π, Σ)`

where:

- `V` stable identities;
- `X` state/lifecycle;
- `C` context/environment;
- `T_N` selected North orientation tree;
- `E_B` other broader contexts;
- `E_R` semantic Roads;
- `E_P` provenance/derivation;
- `E_T` temporal/version relations;
- `E_A` argument/support/attack/contradiction;
- `E_D` Door/state transitions;
- `E_F` quantitative flow/dependency where meaningful;
- `A` preserved artifacts/sources;
- `Π` Views/projections;
- `Σ` schemas, invariants and validators.

This is not a demand for fourteen databases. It is a reminder that different structures answer different questions.

## What appears to survive all lenses

1. **Identity is stable; role is stateful.**
2. **Context is first-class.**
3. **One North is orientation, not ontology.**
4. **Boundaries should enable composition rather than flattening.**
5. **Mountain and Tree are different operations.**
6. **Provenance/history are active system state, not dead metadata.**
7. **Contradiction is data when properly typed.**
8. **Healthy growth alternates expansion with gardening/consolidation.**
9. **Public simplicity requires backend expressive variety.**
10. **Every transformation should declare what changes and what remains invariant.**

## Public website principle

> **A good information architecture does not require the visitor to understand the information architecture.**

The main public experience should not require vocabulary such as Node, Road, Artifact, graph layer, current summit or canonical registry.

A normal subject surface should make it easy to answer:

1. What is this?
2. Where am I / what context am I in?
3. What matters here now?
4. What is connected to this, and why?
5. How did it change?
6. What supports this account?
7. Where can I go deeper?

Search remains useful, but as a **temporary corridor through permanent Rooms**, not as the ownership architecture.

## Promotion boundary

Do not immediately rewrite runtime code from this collection.

Before any replacement architecture becomes constitutional it must:

- survive the 17 stress cases;
- preserve the existing epistemic firewall;
- show that the new distinctions reduce exceptions rather than add another framework layer;
- demonstrate a cleaner public experience;
- provide an explicit supersession/migration path for the recent Atlas experiment;
- retain the good infrastructure already built: stable IDs, provenance, typed relations, static build, CSS ownership, validators and compatibility routing.

## Compact research stance

> **Match complexity in the backend; compress complexity at the interface. Preserve history; rebuild Views. One center can orient many paths without pretending reality is one tree.**
