# Advanced Mathematical Candidates

**Status:** exploratory research only. None of these should be promoted merely because they are mathematically sophisticated.

The project already has simpler graph, temporal, provenance and projection tools. The candidates below earn implementation only if those simpler tools become inadequate for a concrete problem.

## Spectral graph analysis

For a selected non-geographic graph with adjacency matrix `A` and degree matrix `D`:

`L = D - A`

Laplacian eigenvectors/eigenvalues can support deterministic graph layouts and broad connectivity diagnostics.

Possible uses:

- non-geographic relationship observatory;
- component/cluster structure;
- comparing connectivity across graph versions;
- stable layout alternative to random force-directed initialization.

Boundary: spectral proximity is representation of the chosen graph, not real-world geographic, moral, causal or epistemic distance.

## Hyperbolic hierarchy

Deep branching structures are expensive to display in Euclidean space because node count grows rapidly with depth. Hyperbolic geometry allocates increasing representational room toward the boundary.

Candidate uses:

- deep North/Tree navigation;
- provenance/source hierarchy;
- very large Room/neighborhood exploration.

Boundary: this is a separate abstract View, never a distortion applied to Earth geography.

## Hodge decomposition for dimensioned flows

For a directed quantitative edge flow, combinatorial Hodge theory can decompose:

`X = X_gradient + X_curl + X_harmonic`

Potential interpretation in a valid dataset:

- gradient: broad source-to-sink tendency;
- curl: local circulation;
- harmonic: larger cyclic structure not reducible to local loops.

Candidate domains:

- trade;
- finance;
- energy;
- migration;
- information/data flows.

Promotion gate:

- directed edges;
- common/compatible quantity;
- units;
- reference period;
- adequate source coverage;
- declared orientation convention.

Do not apply to undirected symbolic relations.

## Topological persistence

A graph cluster or cycle may appear only because one threshold was chosen.

Persistent-homology/topological-persistence methods can ask which structures survive changes in:

- edge-weight threshold;
- confidence threshold;
- time window;
- sampling/data coverage.

Potential benefit: distinguish stable structural features from threshold artifacts.

Boundary: persistence in a mathematical filtration does not mean metaphysical permanence or causal importance.

## Local-to-global consistency / sheaf-like methods

Many Rooms expose local information about the same canonical identity. The practical problem is whether overlapping local views agree where they should.

A sheaf-like interpretation treats local data plus compatibility maps as a local-to-global consistency problem.

Potential audit targets:

- same ID with incompatible immutable attributes;
- overlapping validity intervals carrying contradictory single-valued facts;
- local projection diverging from canonical owner;
- route aliases resolving to incompatible identities;
- inconsistent epistemic typing across representations.

Start with ordinary consistency validators. Promote actual cellular-sheaf mathematics only if the overlap structure becomes sufficiently complex to justify it.

Expression:

> **Local context may differ; shared identity should glue consistently or expose explicit contradiction.**

## Formal Concept Analysis

Formal Concept Analysis derives concept lattices from object-attribute incidence.

Possible research use:

- discover candidate neighborhoods from actual recurring attributes;
- reveal hidden cross-domain groupings;
- test whether current categories are too coarse.

Boundary: discovered concepts are analytical candidates, not canonical ontology. Human/editorial review remains necessary.

## Category-theoretic composition

Open-system / cospan mathematics is a formal neighbor for House/Rooms: differentiated systems compose through interfaces.

Practical lesson already usable without category-theory code:

> **Composition should happen at interfaces, not by erasing boundaries.**

Potential future use only if a real family of interoperating subsystem contracts needs mathematically guaranteed composition.

## Selection principle

For every advanced formalism ask:

1. What concrete repeated problem cannot simpler structures solve?
2. What data/schema assumptions does the formalism require?
3. What output would become more useful or more correct?
4. How can the result be validated?
5. What false interpretation is likely if the formalism is visualized publicly?
6. Can we obtain 80% of the value with a simpler validator, query or typed relation?

If question 6 is yes, use the simpler tool.
