# Axis / Relational Spine — Research Inspiration Pass

Updated: 2026-09-11
Status: research/design note; not a canonical empirical claim

## Purpose

This note turns the D1–D11 Axis from a stack of symbolic labels into a research programme for a relational Atlas. The governing rule is that the same canonical relation can have a material D4 body and additional projections through provenance, thresholds, recurrence, generativity, composition, relay, integration and orientation.

The Axis is a spine running downward and upward from Earth/D4. In Potatoverse symbolism it can be read through world-tree, ladder, mountain, underworld, throne, wheel-within-wheel and North/North-of-North imagery. Those symbolic correspondences are inspiration for interface and analytical operators, not evidence that myths describe literal physical layers inside Earth or space.

## 1. Treat the Axis as a reference frame, not a score

Do not assign every country or relation one universal height. Instead, expose several coordinates:

- geography: where the observable object is
- time: when the relation exists
- flow: what moves and in which direction
- bond: what maintains the relation
- dependence: how difficult it is to replace or exit
- epistemic visibility: how the relation is known
- dynamics: growth, decay, recurrence, threshold, cascade, repair
- Axis projection: which D-operators reveal useful aspects of the same relation

This keeps `North` from becoming an arbitrary moral rank. Geographic north remains geographic. Project-symbolic North is an orientation/reference concept. North-of-North is a meta-level question about the criteria by which lower views are judged.

### Meaning / orientation

This is where the project-symbolic Axis may operate. It should reference the empirical variables above without overwriting them.

Examples:

- D5 = threshold, authorization, maturity, accession, settlement
- D6 = recurrence with measurable change
- D7 = downstream capability generated
- D8 = composition of differentiated actors with shared interfaces
- D9 = transmission and relay fidelity
- D10 = system-level aggregate and leverage
- D11 = criteria/invariants/objectives used to compare whole-system outcomes

## 3. External theories that fit the spine

### Multilayer / multiplex networks

Real systems contain several kinds of edges between the same nodes. Trade, finance, alliance, migration, information and culture should therefore remain distinct layers instead of being flattened into one generic connection.

Design consequence: the map should support one canonical node pair with multiple typed edges and should show edge overlap, layer dependence and cross-layer effects.

Reference: Kivelä et al., *The structure and dynamics of multilayer networks*; Nature Physics review on real-world multilayer networks.

### Directed hierarchy / trophic analysis

Directed networks can contain a measurable global directionality. Trophic-level methods have been used on supply chains, ecosystems and other directed systems to identify who feeds, supplies or influences whom.

Design consequence: some apparent vertical structure can be derived from real directed flows rather than manually assigned. A supply chain, financial chain or information chain may have an empirically derived upstream/downstream ordering that can be compared with, but not confused with, the symbolic Axis.

### Signed networks and structural balance

Relations can be positive, negative, cooperative, antagonistic or mixed. Signed-network research studies how friendship/alliance and hostility/conflict coexist and how triads or larger structures become balanced or tense.

Design consequence: add valence/status to relations without forcing all relations onto a good/evil line. A positive alliance can still produce negative externalities; an adversarial relation can still be stable.

### Gravity models

Economic geography uses gravity-style models in which relation strength is related to economic mass and distance/trade costs.

Design consequence: calculate `observed vs expected` relation strength. If two large nearby economies trade far less than a gravity baseline predicts, that gap itself is informative. The same logic may be adapted carefully to migration or other spatial flows when a validated model exists.

This creates an important derived relation:
`relation surprise = observed flow - model-expected flow`.

### Input-output / value-chain systems

Inter-country input-output tables explicitly connect production, intermediate inputs, final demand and value added across countries and industries.

Design consequence: D4 can show actual production flows; D7 can expand downstream branches; D8 can show shared production systems; D10 can show systemic dependency, concentration and value-added exposure.

Useful source: OECD ICIO/TiVA.

### From-whom-to-whom finance

IMF and BIS datasets already contain exactly the bilateral structure the Atlas needs: portfolio holdings by counterpart, direct investment positions by counterpart, international bank claims/liabilities, maturity and sector breakdowns.

Design consequence: finance should become a true edge network, not a country statistic panel. The same country can simultaneously be debtor, creditor, investor, issuer, guarantor and intermediary across different instrument layers.

Useful sources:
- IMF Portfolio Investment Positions by Counterpart Economy (formerly CPIS)
- IMF Direct Investment Positions by Counterpart Economy (formerly CDIS)
- BIS Locational Banking Statistics
- BIS Consolidated Banking Statistics

### Network controllability / observability

Control theory asks what parts of a system can be observed and what inputs can steer its modeled state. Complex-network research warns that real networks are heterogeneous and operate at multiple scales.

Design consequence: D10 should distinguish `important`, `observable`, `controllable`, `vulnerable`, and `leverage point`. These are not synonyms. Do not call a node controllable unless a dynamical model actually supports that claim.

### Percolation / robustness / cascading failure

Interdependent infrastructure networks can fail in cascades when dependencies cross layers.

Design consequence: add resilience views that remove or degrade nodes/edges and measure what remains connected. Good candidates include electricity + telecom + transport + fuel + finance. This makes a genuine lower-spine failure/collapse analysis possible without moral language.

Candidate metrics:
- largest connected service component after disruption
- redundancy
- alternate paths
- single-point-of-failure exposure
- restoration time
- cross-layer cascade depth

### Panarchy / adaptive cycles

Panarchy models nested adaptive cycles of growth, conservation, release and reorganization across multiple scales.

Design consequence: this is a strong real-system analogue for Spiral / wheel-within-wheel. D6 does not need to be a camera rotation; it can compare nested cycles at the firm, sector, country, region and world level.

Possible states:
`growth -> conservation -> release -> reorganization -> changed growth`.

### Hyperbolic geometry

Hyperbolic spaces are useful for tree-like and hierarchical networks because they can represent rapid branching with less distortion than ordinary Euclidean layouts.

Design consequence: Tree/Rooms should eventually have a separate graph projection rather than forcing all hierarchy onto geographic 3D space. D7/D8 could use a hyperbolic or radial hierarchy view while preserving links back to real D4 geography.

### Topological data analysis

Topological data analysis studies robust shape features in high-dimensional data, including clusters, loops and holes.

Design consequence: experimental only. It could identify persistent communities, loops or structural gaps across changing thresholds. Do not expose mathematical topology as spirituality. If useful, it belongs under advanced analysis.

## 4. A more useful interpretation of the lower spine

The lower spine should not mean simply `bad things below Earth`.

A more functional reading:

- D4: observable relation
- D3: what is buried underneath it — history, provenance, inherited terms, accumulated obligation, path dependence
- D2: when the relation becomes a self-maintaining loop — recurrence, opacity, capture, blocked exit, cascading dependency
- D1: modeled closure/collapse — near-terminal lock-in, no viable pathway, disconnected or failed system state

This allows generative roots to remain D3 while destructive capture can descend to D2/D1.

### Ma'at / Hall-of-Two-Truths interface inspiration

Ancient Egyptian afterlife imagery uses a balance, a criterion (Ma'at/order/truth), judgment, witnesses/recording and an outcome. Use this only as a symbolic comparator.

Potential Atlas operator: `Reconcile`.

For an obligation or disputed relation, show:
- claim
- counterclaim
- source/evidence
- quantity and unit if measurable
- responsible counterparty
- due/threshold date
- contradictions
- settlement actions
- open/closed/released state

That turns the underworld metaphor into an evidence/ledger mechanism rather than literal cosmology.

## 5. A more useful interpretation of the upper spine

- D5 Door: conditions that change regime
- D6 Spiral: repeated state with a delta
- D7 Tree: downstream capacity/descendants
- D8 Garden/Rooms: modular composition without loss of identity
- D9 Relay/Angels: faithful transmission between differentiated nodes
- D10 Crown/Mountain: integrated system view and leverage
- D11 North-of-North: criteria by which the integrated system is evaluated

`Higher` means more composed or abstract analysis, not necessarily morally superior.

## 6. North and North-of-North

Separate three meanings:

### Geographic north

Literal Earth coordinate. No symbolic inference.

### Project North

A project-symbolic orientation vector: a chosen direction of integration/order within the Axis framework. It may be visualized near the geographic North only because that is part of project canon, but the data model must keep the concepts separate.

### North-of-North

Not a new physical place. Treat it as a meta-reference layer containing competing criteria/objectives.

Examples:
- resilience
- autonomy
- prosperity
- fairness
- sustainability
- peace/security
- openness
- redundancy
- efficiency
- adaptability
- truth/evidence quality

D11 should not output one universal answer. It should expose tradeoffs and allow the user to see what changes when criteria change.

Possible object:
`orientation = {criterion, weight, scope, time, evidence, affected D4 outcomes}`.

## 9. New Atlas views suggested by the research

### Relation Prism

Select one edge. Keep D4 facts visible. Around it show tabs or a D-strip for:
- Roots/provenance
- Terms/thresholds
- recurrence/delta
- downstream consequences
- institutions/shared systems
- relays
- aggregates
- criteria

### Flow mode

Animate only flows whose units/time semantics are known. Width = magnitude; arrow = direction; animation speed only if a rate is meaningful.

### Dependency mode

Show what happens if the edge disappears. Highlight substitutes, alternate routes, exposure and recovery.

### Balance-sheet mode

For one country/entity, show assets and liabilities by counterpart, instrument, currency, maturity and sector instead of one debt number.

### Supply-chain Tree

Choose a commodity/industry/company and expand upstream suppliers and downstream dependent sectors/countries.

### Relay mode

Source -> intermediary -> destination for finance, data, knowledge, diplomacy, migration/remittance or other well-defined flows.

### Wheel mode

Show nested cycles at multiple scales. The same event can be part of a quarterly financial cycle, annual budget cycle, multi-year investment cycle and longer institutional cycle.

### Resilience / failure mode

Temporarily remove an edge/node and recompute connectivity/dependency. This should be clearly marked as analysis/scenario, not current fact.

### Expected-vs-observed mode

Use validated baselines (for example gravity models for trade) to surface unexpectedly strong or weak relations.

## 10. One important visual rule

The 3D map should not physically stack eleven duplicate Earths.

Better:
- Earth/D4 remains the spatial substrate.
- selected relationships can rise or descend along a central Axis/spine as analytical projections.
- abstract hierarchy can branch into Tree/Rooms views outside geographic space.
- nested cycles can orbit the spine as Wheel/Spiral views.
- North-of-North can sit as a meta-orientation panel rather than an invented geographic location.

This preserves the mythic visual grammar while keeping the data model honest.

## 11. Recommended incremental implementation order

1. Build a generic relation-inspector model around the newly extended relational-edge schema.
2. Add bilateral trade as the first true magnitude-carrying flow layer.
3. Add one finance layer (IMF portfolio or BIS banking) and prove stocks/flows/units/time work correctly.
4. Add derived dependence metrics such as counterparty share, concentration and substitutability.
5. Add migration/research/treaty layers to prove multiplex relations between the same country pair.
6. Add D3 provenance and D5 threshold panels to the edge inspector.
7. Add D6 temporal delta and nested-cycle support.
8. Add D7 downstream dependency expansion.
9. Add D8 institution/system composition.
10. Add D9 relay chains.
11. Add D10 aggregate system diagnostics: concentration, centrality, resilience and exposure.
12. Add D11 objective/criterion comparison only after lower layers are evidence-backed.
