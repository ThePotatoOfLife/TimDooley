Culture

Culture is the changing system through which creative expressions are produced, transmitted, encountered, interpreted, reproduced, transformed and remembered. This layer exists to make those processes researchable.

What this layer is for

Culture is not collected here merely as a list of subjects. Records are structured so the repository can later calculate or investigate population, geography, networks, propagation, production, consumption, participation, institutionalization, economics and historical change.

The empirical layer remains distinct from the project's symbolic Potatoism reading of creativity. Claims about membership, influence, control or population require evidence.

Core lifecycle: potential → idea → creation → object → encoding → transmission → attention → reception → participation → community → reproduction → mutation → selection → institutionalization → memory → revival or transformation.
